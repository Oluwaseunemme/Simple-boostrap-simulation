# Simple-boostrap-simulation
Project contain schmatic simualtion proteus file of 555 timer based boostrap H-bridge switching
  The schmatic uses 4 Mosfet irfz44n to switch a 10mH inductor in a full bridge configuration while getting switching signal from a 555 timer and inverters at 0.5Hz for visualmonitoring, it uses capacitor, diode and NPN transistor for high side boostrap network.
